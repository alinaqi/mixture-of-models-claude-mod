‏mixture-of-models إضافة (plugin) لـ Claude Code تعمل بالكامل على جهازك. لا يوجد خادم يديره المؤلف، ولا حساب، ولا قياس عن بُعد (telemetry).

## ما ترسله الإضافة، وإلى من

- **إلى Palgu على `https://api.palgu.ai`**، فقط عندما تشغّل `/palgu`: عند `/palgu login`، اسم العميل `mixture-of-models`، واسم جهاز (`Claude Code on <your HOSTNAME>`)، وإصدار الإضافة ومعرّف تثبيت عشوائي، ثم رمز تسجيل الدخول الذي أصدره Palgu؛ وعند `/palgu status`، مفتاح البوابة الخاص بك، لسؤال Palgu عن صاحبه، وفقط عندما تكون البوابة المضبوطة لديك هي Palgu. المفتاح الذي يعيده Palgu يحفظه Claude Code في تخزينه الآمن عبر `claude plugin configure --values-stdin`، ولا يظهر أبدًا في سطر أوامر.
- **إلى Palgu على `https://api.palgu.ai/v1/pricing/quote`**، بعد دور موجَّه وفقط عندما تكون البوابة المضبوطة لديك هي Palgu: معرّف النموذج وأعداد التوكنات الأربعة للدور، مع مفتاح البوابة، حتى يسعّر Palgu الدور لتقدير التوفير. بلا أي نص من المطالبة أو الإجابة.
- **إلى GitHub (`raw.githubusercontent.com`)**، عند بدء الجلسة مرة كل 12 ساعة على الأكثر وعندما تشغّل `/route update`: طلب GET بسيط لملف البيان (manifest) المنشور للإضافة، لقراءة أحدث إصدار. لا يُرسل شيء عنك أو عن عملك.
- **إلى Ollama محلي على `http://localhost:11434`**، إن كان يعمل: نص كل مطالبة ترسلها، مع معيار تقييم (rubric)، لتُمنح المطالبة درجة من 1 إلى 10. لا يغادر شيء جهازك لهذا الغرض.
- **إلى Anthropic، عبر عميل API الخاص بـ Claude Code وحسابك أنت**، عندما لا يجيب أي Ollama: نص المطالبة نفسه ومعيار التقييم، للحصول على الدرجة نفسها. هذه هي القناة نفسها التي يستخدمها Claude Code أصلًا لجلستك.
- **إلى البوابة التي تضبطها** (`gateway_url`: مثلًا Palgu على `https://api.palgu.ai/anthropic`، أو OpenRouter على `https://openrouter.ai/api`، أو وكيل LiteLLM تشغّله أنت)، عبر عملية Claude Code فرعية موثَّقة بمفتاح `gateway_key` الذي تقدمه (بصفة `x-api-key` لـ Palgu والبوابات العامة، وبصفة توكن `Authorization: Bearer` لـ OpenRouter و LiteLLM): للأدوار الموجَّهة فقط، مطالبتك مع موجز قصير لآخر بضعة تبادلات من جلستك (نص فقط، مقتطع)، وكل ما ترسله حلقة الوكيل الخاصة بتلك العملية الفرعية أثناء عملها. تخضع معالجة البوابة لتلك البيانات لسياسة مشغّل البوابة، لا لهذه الإضافة. يحمل كل طلب من طلبات العملية الفرعية أيضًا ترويستين تعرّفان بها لدى البوابة: `x-srooter-client: mixture-of-models/<version>` (اسم الإضافة وإصدارها) و `x-srooter-project: <folder name>` (آخر جزء من مجلد العمل للجلسة، بأحرف صغيرة ومقتصرًا على `a-z 0-9 . _ -`). لا تحملان أي مسار ولا نص مطالبة ولا أي محتوى آخر، وتُرسلان فقط إلى البوابة المضبوطة، وفقط عندما تكون Palgu أو بوابة عامة متوافقة مع Anthropic: لا يتلقاهما OpenRouter ولا LiteLLM. إذا لم تُضبط أي بوابة، فلا يُرسل شيء وتكون الإضافة في وضع المراقبة فقط.

- **إلى Anthropic، عبر تسجيل دخولك أنت إلى Claude**، فقط للمسارات التي تسمّي عضوًا من عائلة Claude (`claude/sonnet`، `claude/auto`، …): ترسل عملية Claude Code فرعية الموجز نفسه، وكل ما ترسله حلقة الوكيل الخاصة بها أثناء عملها، عبر الحساب نفسه الذي تستخدمه جلستك الرئيسية.
- **إلى نقطة نهاية Codex**، فقط لمسارات `codex`: تقرأ عملية `codex exec` فرعية الموجز نفسه (مطالبتك مع التبادلات الأخيرة المقتطعة)، ويمكنها قراءة الملفات في مجلد عمل الجلسة (مستودع git، ما لم تضبط `codex.allowOutsideGit`) داخل صندوق حماية (sandbox) للقراءة فقط بلا شبكة، ولا يمكنها تعديل الملفات هناك إلا إذا وافقت على أمر رُفض لها في ذلك الدور، أو ضبطت `codex.sandbox` بنفسك على `workspace-write`، وترسل ما تحتاجه حلقة الوكيل الخاصة بها إما إلى نقطة النهاية `/v1/responses` في بوابتك (مع `codex.auth: "palgu"`، وهو الافتراضي، باستخدام `gateway_key` الخاص بك، الذي يُمرَّر إليها في بيئتها فقط؛ على OpenRouter هي `https://openrouter.ai/api/v1/responses`، وعلى LiteLLM هي `/v1/responses` في وكيلك) أو إلى OpenAI (مع `codex.auth: "chatgpt"`، عبر تسجيل دخولك أنت إلى Codex، وفق سياسة OpenAI). قد يحتفظ Codex بملفات جلساته الخاصة تحت `~/.codex`، كما يفعل حين تشغّله بنفسك؛ ولا تقرأ الإضافة ذلك المجلد ولا تكتب فيه أبدًا.

لا ترسل الإضافة شيئًا إلى أي طرف آخر، ولا شيء إلى المؤلف.

## ما تخزنه الإضافة

في مخزن إضافات Claude Code على جهازك: معرّف تثبيت عشوائي يُستخدم لتسجيل الدخول إلى Palgu، وإعداد `/route` الخاص بك، والمجاميع الجارية للتوفير (مبالغ بالدولار مسعَّرة بالتوكنات وأعداد الأدوار)، وأعداد يومية لأي نموذج أجاب، وآخر حكم (verdict)، وأعداد الإخفاقات لكل نوع، وسجل لآخر 200 قرار توجيه (اليوم، النموذج، النوع، المستوى، الدرجة، أي مصنِّف أجاب، مدة العملية الفرعية ورمز خروجها). لا تخزن الإضافة أي نص مطالبات أو إجابات أو بيانات اعتماد. يخزن Claude Code مفتاح البوابة الخاص بك في تخزينه الآمن بوصفه خيار إضافة حساسًا.

## ما تقرؤه الإضافة

`~/.claude/model-config.json` (إعدادات التوجيه، بلا بيانات اعتماد) ومتغيرات البيئة `HOME`، و `HOSTNAME` (لاسم جهاز Palgu)، و `MAGGY_ROUTER_CHILD` و `ANTHROPIC_CUSTOM_HEADERS` (فقط كي تبقى الترويسات المخصصة التي تضبطها بنفسك في طلبات العملية الفرعية إلى البوابة).

## الأطفال

الإضافة غير مخصصة للاستخدام من قِبل أي شخص دون 18 عامًا.
